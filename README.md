# Балкан Гриль — демонстрационный сайт

Статический адаптивный лендинг для «Балкан Гриль», г. Королёв, ул. Марины Цветаевой, 3А.

## Запуск

Откройте `index.html` в браузере. Для локального сервера:

```bash
python -m http.server 8000
```

После этого откройте http://localhost:8000/.

## Что реализовано

- адаптивная главная страница, фиксированное меню, мобильная навигация;
- карточки реальных блюд с переключением категорий;
- ссылки на ранее указанный онлайн-заказ, телефон, карты, социальные сети;
- сведения о бонусной программе;
- SEO-метатеги, доступная разметка;
- **все изображения SVG лежат локально в папке `assets`** — внешних изображений нет.

## Перед показом клиенту / публикацией

1. Убедиться, что текущая ссылка на систему заказа https://balkangrillk.smartofood.ru/ действительно работает.
2. Уточнить цены, граммовки и наличие блюд: данные ориентировочные, собраны из публичного меню агрегатора за октябрь 2026 года.
3. Сверить условия бонусной программы с владельцем.
4. Заменить художественные SVG-иллюстрации на оригинальные фотоснимки блюд заведения, если клиент их предоставит.
5. Сверить фирменный логотип: сейчас в макете оригинальная авторская стилизация, а не точная копия логотипа.
